# printlab

CAD-to-print pipeline for a Creality K2: parametric CAD (CadQuery), printability checks,
renders, STL export and headless slicing (OrcaSlicer CLI with Creality's K2 profiles).
Runs on a Windows 11 PC (`setup/win_setup.ps1`) or in a Claude Code cloud session (`setup/cloud_setup.sh`).
Project notes, rules and print log: `CLAUDE.md`.
